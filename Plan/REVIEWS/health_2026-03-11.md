## Greatest Risk
**Missing alembic migration for function_name column.** TM2 added `function_name` to the `ToolCapability` ORM model but no migration 009 exists. Tests pass because they use `Base.metadata.create_all` (creates full schema). Any production deployment with Alembic will crash on function-level capability queries because the column does not exist in the database. The fix is a one-line `ALTER TABLE tool_capabilities ADD COLUMN function_name VARCHAR(64)` migration. This must be created before TM3 (which depends on per-function grants working end-to-end).
